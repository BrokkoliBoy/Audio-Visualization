# Terrain View - Feature Overview

What the Terrain view can do today and what is planned. The terrain is a mesh whose vertex heights come from
a noise pattern, the audio spectrum and a few beat effects. Everything below is reachable in the slide-in menu
(Tab) unless noted.

Last updated: 2026-10-26 (pattern layers are heights with their own Depth and Mix and the Mode list Replace / Add / Subtract / Highest / Lowest / Multiply / Difference, profiles are now called presets (also classes, files and folders), round shapes fit the disc at zoom 1, mesh morph Pillar, Color mapping window with Color by pattern, windows start open, slider labels shrink to fit, zoom range per pattern, Color blending slider, Floor glow as share of the base glow, green-to-red background on Max FPS, menu navigation window, window titles follow pattern and shape names, thin line edge cues, mesh keeps its dampened values on a detail change, integer sliders snap to whole values, Every n-th beat for waves, Shift + wheel on sliders = 5 times larger steps, right click on a header folds the window, automatic window hues and subheading colors, Blend frequencies, FPS text says "less speed" for fast patterns, sentence case for labels, layer tabs of noise pattern and audio shape pick by dip or click, not by hover, automatic Efficiency (formerly Noise every) by pattern speed, renamed sliders (Reduce peaks, Detail level, Strength, Origin, Beat reaction and Slow swing in Mesh morph, Reset terrain / Reset camera), Planet is the default morph shape, Camera sway on and Zoom on beat off by default, speed hint on low FPS, FPS display and hint also in the Terrain window, mouse wheel on sliders and tick boxes, foldable menu groups, pause keeps the picture, Color tab layout, slider previews on the color sliders, brightness and bloom (gradient track in the rounded slider shape, end color exactly where the handle stops; tint, dirt, dampening use plain sliders), height follows zoom slider, smoothing moved to the Terrain tab, Burst jobs, performance settings, seven new audio shapes, spread noise, face count up to 1000, Max FPS, fade in from black, tabs open on hover, color keys share one hue, new gradient key layout, pattern balance, soft top end, color curve and glow scale)

## Menu tabs

Tabs open on hover at once; a click still works.

| Tab | Groups |
|---|---|
| Color | Six groups: Palette (dropdown, save / delete own palettes), Base, Low, Mid and High (one group each with hue, saturation and glow; the swatch in the header shows the color even when folded), Glow (Brightness: overall, track shows the base color dark to bright; header switch for the whole bloom, bloom strength (0 to 1, default 0.6), lens dirt strength (own switch in its heading; both saved with the preset, the background tint does not depend on them), background tint (off = neutral gray)) |
| Terrain | Everything that shapes the terrain, top to bottom: Terrain (detail, height, FPS hint), Noise pattern, Dampening (with smoothing), Noise pattern, Audio shape (circle, square, diamond, stripes, mirrored stripes, rays, spiral, cross, star, rings) that maps the spectrum onto the terrain, up to three layers in one window with tabs, Beat wave (eight rows in two groups), Mesh morph (eight rows in three groups; it is the last group) |
| General | Presets (save / load / delete; the app starts with the preset of the last session, and closing it with unsaved changes asks first; "Copy setup" puts the current setup on the clipboard as text, "Paste setup" adds a setup from the clipboard as a new preset, to send setups between people; a preset holds all colors itself, and saving or creating one with changed colors also saves them as a palette named like the preset), Camera (sway, zoom on beat; remembered; the two Reset buttons: terrain back to the Default preset, camera back to start), Performance (Max FPS, Detail level, Efficiency, pattern speeds, update time), Test signal (signal, level, beat strength, strength from song, freeze noise, edit bands; hotkey T) |

## Features

| Feature | Status | Notes |
|---|---|---|
| Spectrum terrain | done | Bands are cast onto one or more shapes, out-of-bounds handling, smoothing between bands |
| Audio shapes | done | 12 shapes decide which vertex gets which band (bass first), up to three shape layers in one window (tabs Layer 1 to 3, each with shape, strength, zoom, invert, operation and broaden inner bands; layers 2 and 3 start off): Circle, Square, Diamond, Vertical / Horizontal stripes, Mirrored vertical / horizontal (bass in the middle line), Rays (bass left and right, highs up and down), Spiral (one and a half turns at zoom 1), Cross (bass along both middle lines), Star (five points, bands follow the star outline, zoom below 1 fills the notches), Rings (repeating, zoom 1 = two rings). Circle, Spiral and Rings are round: at zoom 1 they fit the disc that touches the four sides of the terrain (the menu zoom is multiplied by 1.414 inside, TerrainShape.DiscZoom), spiral and rings leave the corners out, so a mesh morph like the Twist turns a clean disc without corners (before, the Circle needed zoom 1.41 for that). Presets carry FormatVersion 3 and convert the old zoom of these three shapes (divided by 1.414) on load, so older presets look the same. Zoom stretches the shape or the repetition, Invert swaps bass and highs |
| Dampening | done | Separate up / down factors (default 0.02 each, slider 0 to 0.12), frame-rate independent: time-based smoothing (1 - (1 - k)^(dt * 240)), so 60 and 240 FPS react the same and nothing overshoots; also used by the audio average and the lerp module |
| Noise patterns | done | 27 patterns (Perlin, Simplex, Value, Fractal, Ridged, Billow, Domain warp, Voronoi, Mosaic, Cracks, Rings, Interference, Spiral, Waffle, Hexagons, Bricks, Dots, Pyramids, Flower, Zigzag, Plasma, Tiles, Triangles, Checker, Steps, Cubes, Honeycomb). Start pattern: Domain warp. Speed slider 0 to 10 (half way = 3). Zoom slider per pattern: each pattern has its own lowest, default and highest zoom (table ZoomScale in TerrainNoise); the slider runs over that range, the default sits in the middle (shown as 5), the text goes 0 to 10. A manual pattern change jumps to the default zoom, loading a preset keeps its stored zoom (limited to the range) |
| Pattern layers | done | Up to three patterns mixed (Terrain tab, the three groups share one window: small tabs "Layer 1", "Layer 2", "Layer 3" inside the window under its header show one at a time, picked by a click or a quick dip of the pointer into the tab (in and out on the same side, a fifth deep) or two quick swipes straight through it, one each way (only where both sides are free; not from the side where another tab sits, so Layer 2 only from above or below, Layer 3 also from the right, swipes only up and down; resting on a tab picks nothing, so moving through the menu does not switch layers; same for the audio shape layers; the tab of a layer that is switched off is dimmed, in every layer window), UiGroupSwitch with "Select by dip", the window keeps its fold state when the layer changes; groups "Noise pattern (layer 1)", "Pattern layer 2" and "Pattern layer 3", part of the preset). A pattern is a height: high in the pattern is high in the terrain, Invert turns it upside down. Every layer has its own pattern, "Depth" (how far the lowest point of the pattern lies under the terrain height, 1 = down to the ground; for layer 1 it is the Depth slider of the Noise pattern window), zoom, speed and invert. Layers 2 and 3 also have an on switch, "Mode" (Replace, Add, Subtract, Highest, Lowest, Multiply, Difference) and "Mix" (how much of the mixed result is used, 0 = layers below unchanged). Everything is calculated as carve (how much of the terrain height is taken away, 0 = nothing; TerrainNoise.Combine): Replace takes the carve of the layer, Add lifts the terrain by Depth x pattern (never above the terrain height), Subtract adds the carve of the layer (Depth x (1 - pattern), at most 1), Highest keeps the smaller carve, Lowest the larger, Multiply multiplies the heights (carve a + b - a x b), Difference is the absolute difference of the carves. So layer 2 with Depth 1 reaches the ground even when layer 1 has Depth 0.3 (before, only the Depth of layer 1 set the deepest point). Flip beats flips the whole mix within the deepest Depth of the active layers (TerrainGenerator.CarveReference). Presets of format version 3 are converted on load (TerrainSettingsPresetManager.MigrateToHeightLayers) and keep their look: every pattern is turned upside down (the old value was the carve), the old Depth of the main pattern becomes the Depth of every layer, the old Depth of a layer becomes its Mix, the old modes become Replace, Subtract, Highest (old Minimum), Lowest (old Maximum) and Difference; the old Multiply (carve times carve) has no twin and loads as Highest. Old presets load with layers 2 and 3 off. The noise runs as a Burst job (TerrainNoiseJob), 3 layers at 500 x 500 faces cost about 1 ms more. Perlin now uses Unity.Mathematics noise (looks slightly different from Mathf.PerlinNoise) |
| Height follows zoom | done | Fixed at 0.5, no slider any more (2026-10-23). The terrain height is multiplied by a factor that blends from 1 to 0.354 / noise zoom (limited to 0.35x to 2.5x) with the slider, so shapes keep their slope when the zoom changes (TerrainGenerator.EffectiveTerrainSizeY). Since the zoom range is per pattern, the reference is the zoom at the middle of the slider (display 5) of the current pattern, so display 5 always gives the set terrain height (TerrainGenerator.HeightZoomReference) |
| Pause keeps the picture | done | Space / P freezes the last spectrum (AudioPlayer.GetSpectrumData), the terrain time stands still (noise, waves, beats, morph animation), the dampening stops, so height and color stay exactly as they were, and on resume everything goes on from there without a jump; a menu change (pattern, shape, sliders) snaps the picture once to the frozen moment with the new settings (the band values are replaced by the dampened ones the picture shows, so it does not jump to the raw height), a flowing invert (pattern invert, flip) still glides; the test signal stands in for the song and ignores the pause |
| Invert per pattern | done | The Invert toggle turns the pattern upside down and is remembered per pattern while the menu is open. No pattern is upside down by itself any more (cell patterns used to be, because patterns were carves; they are heights now and stand up from the ground as they are) |
| Flip on the beat | done | "Flip beats" turns the pattern upside down every N beats, with a smooth morph instead of a hard switch |
| Beat wave | done | Ring waves on the beat. Origin: Middle, Edge, Alternate, Bass edge (starts a little inside of the bass). Mode: Add, Floor, Absorb, Subtract (digs the wave height out of the terrain), Minimum (the lower of the terrain and the wave, so the terrain shows only under the ring). Speed is tied to the song's BPM (1 = half the terrain width per beat). "Every n-th beat" (1 to 8) lets a wave start only on every n-th beat, 1 = every beat, saved in the preset |
| Wave trigger | done | Bass has priority, quiet passages stay quiet. A wave starts flat on every beat and grows if the bass gets strong within 0.1 s. Full height at 90 % of the recent loudest bass |
| Color palettes | done | JSON palettes, HDR colors, start palette Lava |
| Saturation / glow mapping | done | Curved saturation slider, weakly saturated colors are dimmed so white does not overpower |
| FPS display + hint | done | FPS display in the Terrain and the Performance window; hint to lower the detail when FPS stays under 60 / 30 (above pattern speed 2 the FPS text says "less speed helps" instead, "less speed, detail!" when under 30). With a pattern speed above 2 and low FPS (under 45, from speed 3 under 57) a row slides in below the speed slider of the noise pattern and layers ("lower the speed"), the rows below move down |
| Performance | done | Mesh update (calculation only, Editor, Domain warp, 16 cores): 115 x 115 faces 13.6 ms at the start, 3.5 ms after the first pass, 0.7 ms now. 400 x 400 faces: 33 ms before, 5 ms now. Heights, colors, dampening, beat wave and morph run as Burst jobs on all processor cores (TerrainJobs.cs). The noise is calculated in parallel, the band of every vertex per shape is cached until a shape or the face count changes, the audio bands are read once per frame, triangles and uvs are only rebuilt when the face count or the hidden out-of-bounds triangles change |
| Performance settings | done | Window "Performance" in the General tab: Max FPS, a copy of the Detail slider (always equal to the one in the Terrain window), "Efficiency" (upper limit, default 8: noise pattern only every n-th mesh update, in between it blends; the work is always spread over the frames; the interval used goes down on its own for fast patterns: 3 from speed 2, 2 from 3, 1 from 4), copies of the speed sliders of every pattern that is on (Pattern speed, Layer 2/3 speed; they slide in and out, equal to the originals), a readout with the face count (follows the detail slider at once) and the mesh update time. The sliders Max FPS (green at 30, yellow peak at 120, full red from 180), Detail level, Efficiency and the speed copies have a green-to-red background that shows how much frame rate a setting costs (speed costs nothing up to 2, then the interval is forced down; detail grows with the square of the faces) and the handle takes the color. Tint background (0 to 1) is part of the preset |
| Fade in from black | done | The app starts behind a black cover that holds for 1.5 seconds and then fades in over 2.5 seconds, so the first image comes up from black. There is no loading screen, the start has no real load time |
| Test signal | done | Replaces the audio with a calm, fixed spectrum to judge effects without a moving song. "Level" reaches up to 3 (above 1 the bands overdrive like loud songs, to judge the colors of heights over 1). Beats always come on the beat of the playing song (120 BPM without one), waves and flips react, also while paused. "Beat strength" lifts all bands on every beat on top of the level, the bass the most; "Strength from song" takes the strength of every beat from the bass of the playing song instead of the slider. "Freeze noise" stops the noise pattern (off at first). "Edit bands" lets the mouse set single bands (left button raises, right button lowers the band under the cursor). The camera beat zoom pauses while it is on. Starts off, not part of a preset. Hotkey T switches it on and off; the settings panel opens when the pointer touches the right screen edge at any height |
| Color by band | done | Three sliders (Hue = place in the gradient, Saturation = brightness, Glow) say how much each comes from the activity of the vertex's frequency band instead of its height. 0 = as before. Lives in the window "Color mapping" |
| Color by pattern | done | Same three sliders (Hue, Saturation, Glow) in the second group of "Color mapping", but from the strength of the noise pattern at the vertex (1 - carve as a share of the deepest layer Depth, so 1 = the part that stands highest, like the height it gives; before layers are mixed with the audio and before the beat wave). Hue 1 = the place in the gradient comes from the pattern alone, so the color no longer depends on the height of the vertex; 0 = as before. Saturation (brightness): weak parts of the pattern go dark (down to 20 %), strong ones keep the color. Glow: strong parts shine up to four times brighter. Works on top of Color by band. Part of the preset (ColorPatternHue / Brightness / Glow, older presets load with 0). Terrain job: TerrainVertexJob.GetColor |
| Gradient layout | done | The key times of the scene gradient (template for the color curve) are 7: a dark start (never brighter than exposure -4.5, whatever the base color is), the base color at 16 %, color 2 as a flat area from 28 % to 34 %, color 3 as a flat area from 50 % to 75 %, color 4 reached at the top (100 %). The colors reach the middle of the terrain earlier, so the high colors show more often |
| Pattern balance | done | Slider "Pattern leveling" (formerly Pattern balance, shown as "Pattern mix" by mistake) in the Color tab (part of the preset, default 1, 0 = off). A noise pattern that is high or low on average would show only the upper or lower colors of the gradient. The balance measures the average of the pattern (a sample of up to 2048 points) and scales the place in the gradient, so the average height of every pattern lands where a typical one does (a carve of half the deepest layer Depth, scale limited to 0.5 up to 3). The color only, not the height. It glides when the pattern changes. At the default settings it moves Pyramids up by about a third and Billow down by about a sixth |
| Soft top end | done | Slider "Soft top end" in the Color tab (part of the preset, default 0 = off). Loud bands can push vertices over height 1, and then they all show the last gradient color. With the slider up, the position in the gradient bends smoothly above 60 % instead of ending hard at 1: heights over 1 keep a little variation and the last color is only approached (reached at about the height of 2). The color only, not the height. Not the same as Pattern balance, which looks at the noise average |
| Color curve | done | The color table of the terrain (the Unity gradient is only the template for the key times and the dark start) is calculated in TerrainColorGroupUI.ApplyColorCurve. The glow of every color follows its menu value and the colors blend in a straight line. The two long color areas are tilted so the height stays readable (no waves any more). Menu (Color tab): "Floor glow" (0 to 1, default 0.05: brightness of the lowest vertices as a share of the glow of the base color, so it follows the base and is no longer a cap; the slider is finer at the low end; older presets get the default), "Color shift" (moves all colors down or up the height), "Color blending" (formerly Color sharpness / hold width, 0 to 1, default 0.5: high = strong blending = narrow long color areas, 0 = widest, 0.5 = as in the scene gradient; presets still store the hold width, so old ones load unchanged), "Plateau tilt" (default 2 exposure steps per full height, 0 = flat areas; steeper for bright colors because the tone mapping flattens steps there; every stretch of the curve keeps at least that slope even if a color then misses its menu glow, by at most one exposure step), "Slope shading" (default 0.15, 0 = off: fake light, the terrain is shaded by the slope of the ground against a fixed light from the front left, in exposure steps up to this value; surfaces facing the light brighter, the others darker, stronger for bright colors; weaker where the glow curve is steep and stronger where it is flat; gives contours where the color is flat, on top of the tilt, a Burst job after the vertex job, TerrainReliefJob), "Tilt mode" (Auto = direction follows the neighbouring colors, Rising / Falling = always the same direction, Locked = the Auto directions are taken once when selected and kept while the glows change, so nothing jumps) and "Hue balance" (default 0 = off; evens out how bright the hues look at the same glow: green and yellow are dimmed, red and blue lifted, up to one exposure step each way, orange is the reference); all seven are saved with the palette and the preset (older files get the defaults, removed wave values are ignored). No key limit, so the key list can grow later. The tool for trying it out is the "Gradient-Werkbank" artifact (same scale as the menu) |
| Glow scale | done | Menu glow 0 to 10: 0 = exposure -5 (nearly black), 3 = exposure 0 (the plain color), 10 = exposure +6. Palettes and presets carry FormatVersion 2 (presets 4) and convert older files (default at 1) on load without changing the look |
| Mesh morph | done | Bends the whole mesh after the heights (shape dropdown with previous / next buttons): Planet, Twist, Tube, Pillar, Dome, Pringle, Flag (a wave runs through the mesh). Pillar (2026-10-25) is a Tube that stands up like an advertising column: it rolls up as the amount grows and turns upright with it, at 1 it is a closed column. The depth of the terrain becomes the height of the column, so with the audio shape "Horizontal stripes" the bass is at the bottom and the highs at the top; the terrain height becomes the distance from the column axis (TerrainMorphJob, preset number 8). It is scaled down to half the size of the flat terrain (TerrainMorphJob.PillarFit) so it fits the picture at the start zoom. Amount slider. The tube rolls up with the amount and is closed at 1 (the radius shrinks, the width stays). Planet and tube are lifted on the screen by 20 % of its height, from amount 0.15 on and fully at 0.6, so the camera keeps looking at the middle (TerrainGenerator.MorphLiftTarget). The lift jumps in place when the shape changes or the morph is switched on, only changes of the amount glide, and it glides back down when the amount goes to 0. Removed: Bowl, Halfpipe and the "On beat" slider (did not work well); old presets with a removed shape show the dome. Smoothing is in the Audio tab, Max FPS in the Expert tab |
| Morph motion | done | Part of the Mesh morph window, which is one window with three groups separated by a thin line: shape and amount, then the beat motion (beat boost, rise time, fall time, springiness: a breath on every beat, smooth or like on a spring), then the slow wave in time with the beats (swing size, swing beats). The sliders are dimmed while the morph is off. The Basic / Advanced hover toggle (swap icon) was tried here and in Wave, Glow and Terrain and then dropped in favor of fewer, bigger windows; the component stays in the code. |
| Lighting window | done | Light tab: only the depth cues now (Height contrast, Slope shading). Color by frequency band moved to the new window Color mapping (2026-10-25). The rest of the former Color Curve went to Gradient and Glow. |
| Color mapping window | done | Light tab, between Lighting and Glow: group "Color by frequency band" (Hue, Saturation, Glow) and group "Color by pattern" (same three), separated by a thin line, with subheadings. Both groups are handled by TerrainGroupUIBandColor |
| Light tab | done | New menu tab between Color and Terrain with the windows Gradient, Lighting, Color mapping and Glow (moved from the Color tab, which now has the palette and the four color windows). |
| Window subheadings | done | Windows with more than one group (Glow: overall, bloom, lens dirt; Gradient: shape, balance; Lighting: depth cues, color by frequency band; Beat wave; Mesh morph) have small capital subheadings in a light tone of the stripe color (calculated from the stripe in UiAccent.TintGroup) and a thin line between the groups. Noise pattern: "Invert all" removed. Smoothing is a checkbox in Dampening. Floor glow moved to Glow, the Gradient window (color shift, hold width, soft top end, hue balance, pattern balance) is new in the Color tab. |
| Dimmed windows | done | While the on / off switch in a window header is off (Mesh morph, Wave, Dampening, Noise and Shape layers, Terrace), all rows of the window are dimmed because they have no effect then (UiGroupDim). Blend frequencies in Dampening stays bright |
| Background tint | done | The middle and bottom of the sky take the hue of the base color, brightness and saturation come from the sky colors in the volume profile. Slider "Tint background" (0 = untinted, 1 = fully tinted) in the Glow window (Light tab, now the last window) |
| Presets | done | All terrain settings except the test signal. Picking an option in the preset dropdown loads it: with a click, with the mouse wheel on the closed dropdown, and as a preview while the list is open (the preset under the pointer shows on the terrain; closing the list without a pick brings back the state from before, unsaved changes included). The Load button still reloads the selected preset (TerrainGroupUIPresets.OnDropdownValueChanged, with DropdownWheel) |
| Camera control | done | Mouse (left drag on the background or middle drag orbits, left drag on the terrain turns it around its middle, right drag moves, wheel zooms; both left and right belong to the band editor while it is on) and keyboard (WASD, Q / E, C resets camera and terrain turn, the reset glides), beat zoom, camera menu (controls overview) and camera switches in the General tab |
| Dropdown mouse wheel | done | The wheel steps through the options of a dropdown while the pointer is on it (forward = previous, back = next, wrapping around at both ends), without opening it |
| Integer sliders | done | Sliders that only carry whole numbers (Detail level, Max FPS, Efficiency, Every n-th beat, Flip beats, Swing beats, hues) rest on whole values: the handle snaps to the nearest one and the change event only fires when the number changes. The mouse wheel moves them by one (Shift + wheel by five on ranges of 20 or more, on shorter ranges it jumps to the end of the range) |
| Menu navigation | done | General tab window "Menu navigation": a main switch plus one tick box each for tabs opening on hover, windows opening on hover, layer tabs switching on hover, layer tabs switching by dip or swipe, and ticking boxes by dip / swipe. Layer hover and layer dip are off by default, tick dip is on. Switching window hover off keeps a window that is open by hovering open. Saved on this computer (not in a preset), "Defaults" resets it. A right click on a window header always folds it |
| Layer tab names | done | The tabs "Layer 1 / 2 / 3" in the pattern and audio shape windows show the name of the pattern or shape of that layer, or "Off" while the layer is switched off |
| Edge cues | done | The cues of the hidden menu (right) and the player bar (bottom) are a dark thin line with a small nose, separated by a small gap (the bottom one looks like the side one; the song progress line at the screen bottom is gone, the player bar shows it). The right cue does not vanish: it moves out with the menu, stays left of it and fades out on the way (and back in when the menu closes) |
| Slider and toggle mouse wheel | done | The wheel changes a slider while the pointer is on it (forward = higher) in steps that fit the slider: automatic about 1/50 of the range (a range of 2 steps by 0.05, Shift keeps 0.2; whole numbers step by 1), set per slider with "Wheel Step" (e.g. hue 1, intensity 0.1, bloom 0.01, dirt 0.02, depth 0.02, detail, height, zoom and speed 0.1). Wheel on a tick box switches it (forward = on, back = off) |
| Foldable groups | done | Coming into a menu tab by hand opens its first window (not pinned), (there are four tabs: Color, Light, Terrain, General). A group opened by hovering stays open when the pointer leaves, until another group opens, so the menu comes back with the last window still there. All groups start folded, in every tab. Clicking anywhere on a menu group header folds or pins it (the tick box on the right keeps its click, its hit area reaches a few pixels to the left); a pinned group keeps a very faint highlight on its header; a small arrow at the left is hidden while the group is folded, fades in pointing right while the group is open by hovering and turns down when it is pinned open. The hover highlight of the header is very faint. A folded group shows only its header and opens as soon as the pointer is on it, sliding open and shut in 0.15 s, closing again 0.3 s after the pointer left (so the pointer can move on to the next group in one go) (not while a mouse button is held or a dropdown list is open). A click on the button pins the group open, another click folds it; Shift + click opens or folds every group of the tab, Ctrl + click every group of all tabs, a right click on the header folds an open group (also one opened by hovering). A group opened by hovering folds when the tab is left. The pointer switches straight from one hover-opened group to the next without a delay. Groups start open. All windows start open except Mesh morph, which starts folded (2026-10-24). Slider labels shrink on their own down to size 9 when too long (maximum 16) |
| Tick box dip | done | A quick dip of the pointer into a tick box and back out on the same side switches it without a click; so do two quick swipes straight through it, one each way within 0.6 s (the turn does not have to hit the box). Only the box itself counts (no margin), the pointer must reach a third into it and be out again within 0.4 s (a swipe through it within 0.3 s); resting on it, passing through, clipping a corner or a real click switch nothing extra. Not while the menu or window slides, a button is held or a dropdown is open. |
| Group color stripe | done | A thin colored stripe at the left of every group header. Every menu tab has its own pair of colors and the groups of the tab run through the gradient in their order (Color: orange to yellow, Light: pink to violet, Terrain: blue to teal, General: green to lime; the hues are calculated from the window order, UiTabs: Auto accents with Hue from / Hue to per tab), so a window can be told from its neighbours by hue. Windows that share a place (pattern layers, shape layers, Mesh morph is one window now) share a color. The accent color also reaches the controls: sliders without their own gradient (fill, handle, track), the step buttons next to dropdowns and the fold arrow take a tone of their window's accent, the marks under the layer tabs use it, and the bar under a menu tab is a gradient of the accents of its windows (dim while the tab is not selected) |
| Number format | done | Numbers are shown and read the English way (1.5 instead of 1,5) whatever the system language is (set once at start) |
| Dropdown preview | done | While a dropdown list is open, the option under the pointer is applied at once as a preview; closing the list without picking brings the old value back |
| Menu trigger area | done | A strip of 80 reference pixels at the right screen edge, over the whole height, always opens the terrain menu. Besides that the menu opens when the pointer is in an area at the right screen edge: 20 % wider than the menu to the left, and as high as the menu right now (folded windows make it shorter) plus 8 % of the screen height above and below. The menu sits a little lower so no background shows above it |
| Menu opens by intent | done | The pointer has to be in the right half of the screen for the terrain menu and in the lower half for the player bar, and a fast movement that misses the menu takes the intent back only after 0.15 s. The terrain menu (right) and the player bar (bottom) open before the pointer arrives: when the pointer moves faster than 0.6 screen heights per second and its path of the next 0.4 s reaches the trigger area, the menu comes and stays 0.9 s after the last movement towards it. Any fast movement elsewhere takes it back, dragging a slider does not count, and a pointer locked for camera steering never triggers it. The trigger area reaches 50 % beyond the menu to the left |
