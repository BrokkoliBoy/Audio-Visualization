# Terrain View - Feature Overview

What the Terrain view can do today and what is planned. The terrain is a mesh whose vertex heights come from
a noise pattern, the audio spectrum and a few beat effects. Everything below is reachable in the slide-in menu
(Tab) unless noted.

Last updated: 2026-10-23 (mouse wheel on sliders and tick boxes, foldable menu groups, pause keeps the picture, Color tab layout, slider previews (brightness, bloom, dirt, dampening), height follows zoom slider, smoothing moved to the Terrain tab, Burst jobs, performance settings, seven new audio shapes, spread noise, face count up to 1000, Max FPS, fade in from black, tabs open on hover, color keys share one hue, new gradient key layout, pattern balance, soft top end, color curve and glow scale)

## Menu tabs

Tabs open on hover at once; a click still works.

| Tab | Groups |
|---|---|
| Color | Six groups: Palette (dropdown, save / delete own palettes), Base, Low, Mid and High (one group each with hue, saturation and glow; the swatch in the header shows the color even when folded), Glow (Brightness: overall, track shows the base color dark to bright; header switch for the whole bloom, bloom strength (0 to 1, default 0.6), lens dirt strength (own switch in its heading; both saved with the profile, the background tint does not depend on them), background tint (off = neutral gray)) |
| Terrain | Everything that shapes the terrain, top to bottom: Terrain (detail, height, FPS hint), Noise pattern, Mesh morph, Dampening, Beat wave (height, speed, mode, origin), Audio shapes (circle, square, diamond, stripes, mirrored stripes, rays, spiral, cross, star, rings) that map the spectrum onto the terrain; Shapes are the last group |
| General | Profiles (save / load / delete), Reset (terrain back to the Default profile, camera back to start), Camera (sway, zoom on beat; remembered), Frame rate (Max FPS and the mesh update time), Test signal (signal, level, beat strength, strength from song, freeze noise, edit bands; hotkey T) |
| Expert | Smoothing (on / off), morph motion (see below), Settings you set once: color curve (floor glow, color shift, hold width, plateau tilt, tilt mode, hue balance, pattern balance, color headroom), color from band, relief light, bloom threshold / spread, dirt on the beat, noise interval and spread noise, beat wave width / fade / use noise, height follows zoom |

## Features

| Feature | Status | Notes |
|---|---|---|
| Spectrum terrain | done | Bands are cast onto one or more shapes, out-of-bounds handling, smoothing between bands |
| Audio shapes | done | 12 shapes decide which vertex gets which band (bass first): Circle, Square, Diamond, Stripes Vertical / Horizontal, Mirrored Vertical / Horizontal (bass in the middle line), Rays (bass left and right, highs up and down), Spiral (one and a half turns at zoom 1), Cross (bass along both middle lines), Star (five points, bands follow the star outline, zoom below 1 fills the notches), Rings (repeating, zoom 1 = two rings). Zoom stretches the shape or the repetition, Invert swaps bass and highs |
| Dampening | done | Separate up / down factors (default 0.02 each, slider 0 to 0.12), frame-rate independent: time-based smoothing (1 - (1 - k)^(dt * 240)), so 60 and 240 FPS react the same and nothing overshoots; also used by the audio average and the lerp module |
| Noise patterns | done | 27 patterns (Perlin, Simplex, Value, Fractal, Ridged, Billow, Domain warp, Voronoi, Mosaic, Cracks, Rings, Interference, Spiral, Waffle, Hexagons, Bricks, Dots, Pyramids, Flower, Zigzag, Plasma, Tiles, Triangles, Checker, Steps, Cubes, Honeycomb). Start pattern: Domain warp. Speed slider 0 to 10 (half way = 3) |
| Pattern layers | done | Up to three patterns mixed (Terrain tab, the three groups share one window: small tabs "Layer 1", "Layer 2", "Layer 3" inside the window under its header show one at a time on hover or click, UiGroupSwitch, the window keeps its fold state when the layer changes; groups "Noise pattern (layer 1)", "Pattern layer 2" and "Pattern layer 3", part of the profile). Layers 2 and 3 have an on switch, their own pattern, zoom, speed and invert, "Mix" (Override, Add, Multiply, Maximum, Minimum, Difference) and "Depth" (how much of the mixed result is used, 0 = layers below unchanged). "Invert all" in the first group turns the whole mix upside down, Flip beats flips the whole mix. Old profiles load with layers 2 and 3 off. The noise runs as a Burst job (TerrainNoiseJob), 3 layers at 500 x 500 faces cost about 1 ms more. Perlin now uses Unity.Mathematics noise (looks slightly different from Mathf.PerlinNoise) |
| Height follows zoom | done | Slider 0 to 1 in the Expert tab (noise group, 0 = off, part of the profile). The terrain height is multiplied by a factor that blends from 1 to 0.354 / noise zoom (limited to 0.35x to 2.5x) with the slider, so shapes keep their slope when the zoom changes (TerrainGenerator.EffectiveTerrainSizeY) |
| Pause keeps the picture | done | Space / P freezes the last spectrum (AudioPlayer.GetSpectrumData), the terrain time stands still (noise, waves, beats, morph animation), the dampening stops, so height and color stay exactly as they were, and on resume everything goes on from there without a jump; a menu change (pattern, shape, sliders) snaps the picture once to the frozen moment with the new settings (the band values are replaced by the dampened ones the picture shows, so it does not jump to the raw height), a flowing invert (pattern invert, flip) still glides; the test signal stands in for the song and ignores the pause |
| Invert per pattern | done | Cell patterns (Voronoi, Cracks, Hexagons, Bricks, Dots, Pyramids, Tiles, Triangles, Cubes) stand up from the ground by default, the Invert toggle flips them. The choice is remembered per pattern |
| Flip on the beat | done | "Flip beats" turns the pattern upside down every N beats, with a smooth morph instead of a hard switch |
| Beat wave | done | Ring waves on the beat. Origin: Middle, Edge, Alternate, Bass edge (starts a little inside of the bass). Mode: Add, Floor, Absorb. Speed is tied to the song's BPM (1 = half the terrain width per beat) |
| Wave trigger | done | Bass has priority, quiet passages stay quiet. A wave starts flat on every beat and grows if the bass gets strong within 0.1 s. Full height at 90 % of the recent loudest bass |
| Color palettes | done | JSON palettes, HDR colors, start palette Lava |
| Saturation / glow mapping | done | Curved saturation slider, weakly saturated colors are dimmed so white does not overpower |
| FPS display + hint | done | Hint to lower the detail when FPS stays under 60 / 30 |
| Performance | done | Mesh update (calculation only, Editor, Domain warp, 16 cores): 115 x 115 faces 13.6 ms at the start, 3.5 ms after the first pass, 0.7 ms now. 400 x 400 faces: 33 ms before, 5 ms now. Heights, colors, dampening, beat wave and morph run as Burst jobs on all processor cores (TerrainJobs.cs). The noise is calculated in parallel, the band of every vertex per shape is cached until a shape or the face count changes, the audio bands are read once per frame, triangles and uvs are only rebuilt when the face count or the hidden out-of-bounds triangles change |
| Performance settings | done | Group "Frame rate" in the General tab (Max FPS and the mesh update time), "Noise every" and "Spread noise" are in the Expert noise group, part of the profile (except Max FPS). "Noise every" (1 to 8) calculates the noise only every n-th mesh update, in between it blends from the last to the next result. "Spread noise" (only with Noise every above 1) does not calculate the whole pattern in one update, but a scattered n-th of the points in every update, each blending on its own: the work is the same in every frame (300 x 300 faces, every 4th: 4.6 and 1.2 ms alternating before, 2.3 ms every update now) and nothing flows in step. "Max FPS" (30 up to the refresh rate of the monitor, 240 Hz here) limits the frame rate of the whole app, e.g. 60 to save energy while working; it is saved on this computer (PlayerPrefs), not in a profile, and starts at the monitor's refresh rate in a build and at 60 in the Editor, V-Sync off. The mesh is updated every frame. The face count is shown as "Detail" from 1 (20 faces) to 10 (1000 x 1000), compressed at the top: 7 = 500 faces is the default and enough for most patterns (about 8 ms per mesh update at 500 and 28 ms at 1000, Domain warp, 16 cores), the high end is for looking at patterns at low FPS. The Terrain tab shows FPS with a hint to lower the detail, the Expert tab the mesh update time in ms. The terrain height starts at 2. Defaults: 1 / off / monitor rate in a build, 60 in the Editor. Tried and removed again: "Noise step" (noise only for every n-th vertex, interpolated in between), "Smooth noise" (Catmull-Rom instead of straight lines between them) and "Mesh Hz" (limit for the mesh updates) - they confused more than they saved |
| Fade in from black | done | The app starts behind a black cover that holds for 1.5 seconds and then fades in over 2.5 seconds, so the first image comes up from black. There is no loading screen, the start has no real load time |
| Test signal | done | Replaces the audio with a calm, fixed spectrum to judge effects without a moving song. "Level" reaches up to 3 (above 1 the bands overdrive like loud songs, to judge the colors of heights over 1). Beats always come on the beat of the playing song (120 BPM without one), waves and flips react, also while paused. "Beat strength" lifts all bands on every beat on top of the level, the bass the most; "Strength from song" takes the strength of every beat from the bass of the playing song instead of the slider. "Freeze noise" stops the noise pattern (off at first). "Edit bands" lets the mouse set single bands (left button raises, right button lowers the band under the cursor). The camera beat zoom pauses while it is on. Starts off, not part of a profile. Hotkey T switches it on and off; the settings panel opens when the pointer touches the right screen edge at any height |
| Color by band | done | Three sliders (gradient position, brightness, glow) say how much each comes from the activity of the vertex's frequency band instead of its height. 0 = as before |
| Gradient layout | done | The key times of the scene gradient (template for the color curve) are 7: a dark start (never brighter than exposure -4.5, whatever the base color is), the base color at 16 %, color 2 as a flat area from 28 % to 34 %, color 3 as a flat area from 50 % to 75 %, color 4 reached at the top (100 %). The colors reach the middle of the terrain earlier, so the high colors show more often |
| Pattern balance | done | Slider "Pattern balance" in the Color tab (part of the profile, default 1, 0 = off). A noise pattern that is high or low on average would show only the upper or lower colors of the gradient. The balance measures the average of the pattern (a sample of up to 2048 points) and scales the place in the gradient, so the average height of every pattern lands where a typical one does (0.5 noise, scale limited to 0.5 up to 3). The color only, not the height. It glides when the pattern changes. At the default settings it moves Pyramids up by about a third and Billow down by about a sixth |
| Soft top end | done | Slider "Soft top end" in the Color tab (part of the profile, default 0 = off). Loud bands can push vertices over height 1, and then they all show the last gradient color. With the slider up, the position in the gradient bends smoothly above 60 % instead of ending hard at 1: heights over 1 keep a little variation and the last color is only approached (reached at about the height of 2). The color only, not the height. Not the same as Pattern balance, which looks at the noise average |
| Color curve | done | The color table of the terrain (the Unity gradient is only the template for the key times and the dark start) is calculated in TerrainColorGroupUI.ApplyColorCurve. The glow of every color follows its menu value and the colors blend in a straight line. The two long color areas are tilted so the height stays readable (no waves any more). Menu (Color tab): "Floor glow" (glow of the lowest vertices on the menu glow scale, default 0.3 = exposure -4.5), "Color shift" (moves all colors down or up the height), "Color hold width" (width of the two long color areas), "Plateau tilt" (default 2 exposure steps per full height, 0 = flat areas; steeper for bright colors because the tone mapping flattens steps there; every stretch of the curve keeps at least that slope even if a color then misses its menu glow, by at most one exposure step), "Relief light" (default 0.15, 0 = off: fake light, the terrain is shaded by the slope of the ground against a fixed light from the front left, in exposure steps up to this value; surfaces facing the light brighter, the others darker, stronger for bright colors; weaker where the glow curve is steep and stronger where it is flat; gives contours where the color is flat, on top of the tilt, a Burst job after the vertex job, TerrainReliefJob), "Tilt mode" (Auto = direction follows the neighbouring colors, Rising / Falling = always the same direction, Locked = the Auto directions are taken once when selected and kept while the glows change, so nothing jumps) and "Hue balance" (default 0 = off; evens out how bright the hues look at the same glow: green and yellow are dimmed, red and blue lifted, up to one exposure step each way, orange is the reference); all seven are saved with the palette and the profile (older files get the defaults, removed wave values are ignored). No key limit, so the key list can grow later. The tool for trying it out is the "Gradient-Werkbank" artifact (same scale as the menu) |
| Glow scale | done | Menu glow 0 to 10: 0 = exposure -5 (nearly black), 3 = exposure 0 (the plain color), 10 = exposure +6. Palettes and profiles carry FormatVersion 2 and convert older files (default at 1) on load without changing the look |
| Mesh morph | done | Bends the whole mesh after the heights (shape dropdown with previous / next buttons): Planet, Twist, Tube, Dome, Pringle, Flag (a wave runs through the mesh). Amount slider. The tube rolls up with the amount and is closed at 1 (the radius shrinks, the width stays). Planet and tube are lifted on the screen by 20 % of its height, from amount 0.15 on and fully at 0.6, so the camera keeps looking at the middle (TerrainGenerator.MorphLiftTarget). The lift jumps in place when the shape changes or the morph is switched on, only changes of the amount glide, and it glides back down when the amount goes to 0. Removed: Bowl, Halfpipe and the "On beat" slider (did not work well); old profiles with a removed shape show the dome. Smoothing is in the Audio tab, Max FPS in the Expert tab |
| Morph motion | done | Group "Morph motion" in the Expert tab (part of the profile). The drawn amount is the Amount slider plus a breath on every beat plus a slow wave. "Beat lift" (0 = off) is how much the amount rises on a beat; "Attack" is the beats it takes to the peak, "Release" the beats back down (a spring follows the target, so nothing jumps); "Bounce" 0 = glides, 1 = swings over the peak. "Wave depth" (0 = off) swings the amount around the slider by this much, one swing takes "Wave beats" (1 to 64) beats. With the Twist shape the drawn amount may go below 0 (down to -1), so wave and bounce turn it the other way: set the Amount slider to 0 and Wave depth up for a swing in both directions. Paused = stands still (TerrainGenerator.UpdateMorphMotion). Not done: shape morph over time, beat steps, loudness coupling |
| Background tint | done | The middle and bottom of the sky take the hue of the base color, brightness and saturation come from the sky colors in the volume profile. Toggle "Tint background" at the end of the Glow group (Color tab) |
| Profiles | done | All terrain settings except the test signal |
| Camera control | done | Mouse (left drag on the background or middle drag orbits, left drag on the terrain turns it around its middle, right drag moves, wheel zooms; both left and right belong to the band editor while it is on) and keyboard (WASD, Q / E, C resets camera and terrain turn, the reset glides), beat zoom, camera menu (controls overview) and camera switches in the General tab |
| Dropdown mouse wheel | done | The wheel steps through the options of a dropdown while the pointer is on it (forward = previous, back = next, wrapping around at both ends), without opening it |
| Slider and toggle mouse wheel | done | The wheel changes a slider while the pointer is on it (forward = higher) in steps that fit the slider: automatic about 1/50 of the range (whole numbers step by 1), set per slider with "Wheel Step" (e.g. hue 1, intensity 0.1, bloom 0.01, dirt 0.02, depth 0.02, detail, height, zoom and speed 0.1). Wheel on a tick box switches it (forward = on, back = off) |
| Foldable groups | done | Clicking anywhere on a menu group header folds or pins it (the tick box on the right keeps its click, its hit area reaches a few pixels to the left); a small arrow at the left points right and is hidden while the group is folded, it fades in while the group is open (by hovering or pinned) and so marks where the pointer is. The hover highlight of the header is very faint. A folded group shows only its header and opens as soon as the pointer is on it, sliding open and shut in 0.15 s, closing again 0.3 s after the pointer left (so the pointer can move on to the next group in one go) (not while a mouse button is held or a dropdown list is open). A click on the button pins the group open, another click folds it; Shift + click opens or folds every group of the tab, Ctrl + click every group of all tabs. A group opened by hovering folds when the tab is left. The pointer switches straight from one hover-opened group to the next without a delay. Groups start open |
